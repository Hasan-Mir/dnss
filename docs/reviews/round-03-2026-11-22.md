## Adversarial Self-Review Findings Fixed Before Packaging

1. **Critical — Win32 Overlapped `CancelIoEx` Stack Use-After-Free (`service.rs`)**: `CancelIoEx(pipe, &ov)` is asynchronous; returning immediately while the kernel completes the cancelled IRP would corrupt stack-allocated `OVERLAPPED` and read buffers in a `SYSTEM` process. Fixed in all three overlapped paths (`read_request_overlapped`, `write_all_overlapped`, `service_main`) by waiting via `GetOverlappedResult(pipe, &ov, &mut dummy, TRUE)` before unwinding.
2. **Medium — CLI Concurrent Pipe `EBUSY` Handling (`packages/cli/src/index.ts`)**: Because `DnssService` intentionally holds `nMaxInstances = 1` with `FILE_FLAG_FIRST_PIPE_INSTANCE`, concurrent CLI + GUI calls can hit `EBUSY`. Added a bounded retry loop (up to 4 attempts with linear backoff) in `sendWindowsServiceRequest`.
3. **Low — Cross-Platform `dead_code` Warnings (`service.rs`)**: Added `#![cfg_attr(not(target_os = "windows"), allow(dead_code))]` and removed unused Win32 constants (`SERVICE_NO_CHANGE`, `WAIT_TIMEOUT`) so Linux/macOS and Windows builds compile warning-free.
4. **Low — `SetDnsOutcome` Wire Deserialization (`lib.rs`)**: Added `#[serde(default)]` alongside `skip_serializing_if = "String::is_empty"` on `SetDnsOutcome.error` so successful outcomes round-trip cleanly over JSON IPC.
